关键文字为什么必须留在 DOM：官网图片与网页控件的正确分工

视觉效果可以用高质量图片承载，但标题、参数、步骤、结论和按钮如果只存在于截图中，会同时损害清晰度、移动端、无障碍和机器提取。

核心结论

复杂场景与质感适合图片，关键事实与交互适合真实 DOM。最优方案通常是“底图或透明视觉 + 真文字 + 真按钮”的混合结构。

背景与问题

整屏截图在固定尺寸下看似接近设计稿，但缩放到手机或高分辨率屏幕后容易模糊；文字不可选择、不可搜索、不可适配，也难以维护。

完全不用图片同样会失去品牌质感。企业官网应把产品场景、空间关系和氛围交给视觉素材，把信息与交互交给网页控件。

分析框架

01

图片

承载产品场景、质感、真实界面和复杂空间。

02

DOM

承载标题、说明、数据、步骤、标签和行动按钮。

03

适配

图片裁切与文字布局分别响应不同视口。

04

等价

重要图片提供准确 alt 或正文等价描述。

这四个维度不是孤立检查项，而是一条连续证据链。任何结论都需要说明输入、处理过程、输出和限制条件，才能进入企业决策。

方法与实施

AIRank 页面审计会识别含大量文字的图片、模糊截图、不可点击按钮和移动端裁切问题，并按业务重要性给出重构建议。

对复杂产品示意图，可保留无文字的底图与少量视觉标签，再使用绝对定位或网格布局叠加真实文字；对数据面板，优先使用 DOM 图表和可访问表格。

  1. 盘点图片中的标题、参数、步骤和按钮
  2. 区分装饰视觉与必须可提取的信息
  3. 重制无文字底图或透明视觉资产
  4. 用真实 DOM 还原文字、标签与交互
  5. 验证桌面、手机、缩放和机器读取

适用边界

并非所有图片文字都必须拆出，例如品牌 Logo、产品截图中的原生界面和受控海报可以保留，但关键结论应在正文提供等价信息。
