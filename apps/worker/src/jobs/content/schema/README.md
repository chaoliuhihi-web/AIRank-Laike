# content/schema — 结构化资产生成

生成帮助 AI 和搜索引擎理解企业内容的结构化数据。

## 资产类型

```text
Organization Schema (JSON-LD)
Service Schema
FAQ Schema
Article Schema
Breadcrumb
sitemap.xml
robots 建议
canonical 建议
```

## 说明

- 结构化数据是 AI 推荐门槛中"技术抓取门槛"的核心解法。
- 这些资产不是独立页面，而是嵌入官网页面的 meta/script 标签。
- sitemap.xml 和 robots.txt 建议需要与发布模块协同。
