# AIRank 控制台体验重构验收记录（2026-08-09）

范围：依据《AIRank 控制台产品体验重构方案》实施客户控制台、交付工作台和平台管理后台分区，并验证数据真实性、响应式与角色边界。

## 已完成改造

- 客户主导航收敛为六步闭环：买家问题、多平台扫描、证据缺口、可信事实、答案资产、发布与复测。
- 任务、证据补录、审核与发布协调迁入交付工作台；Provider、Skill、队列与审计迁入平台管理后台。
- 登录会话携带后端权限，路由在渲染前完成权限过滤；客户设置不再暴露模型、密钥和平台路由控制。
- 新增 `airank.growth-loop.v1` 统一视图，集中输出结论门禁、步骤状态、真实对象数量和唯一下一动作。
- 只有真实 Provider 样本达到本轮门槛时，工作台才展示测量指标；可选子系统读取失败时返回不可用状态，不伪造为零。
- 生产扫描任务在写入前校验 Provider 是否已配置并启用；禁用平台不会继续创建误导性任务。
- 删除生产业务 fallback 导出，加载、错误、空数据和真实数据分别呈现。
- 旧链接保留业务语义迁移，例如 `/console/tasks`、`/console/evidence` 迁移到 `/console/scans`。

## 发现并修复的问题

| 编号 | 问题 | 风险 | 修复与证据 |
| --- | --- | --- | --- |
| UX-001 | 当前步骤匹配对共享路由数组执行原地排序 | 客户侧栏被重排成 06、01、05、02 等错误顺序 | 改为复制数组后排序；浏览器逐项确认顺序为工作台、01—06、客户报告 |
| UX-002 | 移动抽屉保留桌面侧栏滚动位置 | 从靠后页面打开菜单时 AIRank 品牌和工作区切换不可见 | 打开抽屉时同步及动画后复位滚动，并关闭滚动锚定；390px 视口复验通过 |
| UX-003 | 登录响应增加权限但 JSON Schema 未更新 | 契约消费者校验失败 | Schema 增加必填、唯一的 `permissions` 数组；登录契约回归通过 |
| UX-004 | Provider 写入前门禁误伤无数据库的开发契约 | 既有 in-memory API 测试无法构造合成 Provider | 门禁只在持久化生产路径强制；生产阻断测试显式设置数据库环境 |
| UX-005 | 问题来源精简后缺少“次数不是搜索量”的完整提示 | 客户可能误把自有资料频次理解为全网需求 | 恢复“客户提供观察记录（未独立核验）”与频次边界文案 |
| UX-006 | 本机默认 Node 20.18.2 低于 Vite 要求 | 构建有版本警告 | 最终构建改用 Codex 内置 Node，Vite 警告消除；包体门禁通过 |

## 验收结果

- Python 全量测试：`670 passed, 40 skipped`。
- Web：TypeScript 与 Vite 生产构建通过；最大 JavaScript 分包小于 512 KB。
- 浏览器：登录页全中文并显示 AIRank LOGO；客户七个入口、交付五个入口、管理四个入口逐项可达。
- 响应式：桌面与 390px 手机视口通过；移动抽屉、六步顺序、空态和主按钮无横向溢出。
- 旧路由：`/console/tasks` 实测迁移到 `/console/scans`。
- 浏览器控制台：本轮验收无 error 或 warning。
- 动态空证据链：本地隔离项目在无真实 Provider 证据时保持“待验证/结论受阻”，下游步骤不伪装完成。

## 仍不等同于商业发布完成

本次验收证明控制台重构与工程回归通过。Kimi 已暴露旧凭证轮换、DeepSeek 可持续型号额度、Consumer Web/App 四平台 L3、生产 KMS/HSM、客户站点发布回执和完整复测窗口仍按现有上线门禁管理；任何 `blocked/partial/disabled` 不得包装成商业可用。
