# AIRank 单机生产体验环境问题与修复记录（2026-08-09）

目标环境：`101.200.137.138` 数据盘部署，正式体验域名 `https://console.airank.net.cn`。

本记录只描述可复核事实。体验环境可用不等于商业发布门禁已经通过。

| 编号 | 发现问题 | 风险 | 处理结果 | 验收证据 |
| --- | --- | --- | --- | --- |
| DEP-001 | 域名最初返回 Nginx 502 | 用户无法访问 | 修复反向代理上游并恢复 API/Web 容器 | HTTPS 首页、`/healthz`、`/api/v1/health` 均为 200 |
| DEP-002 | 根盘空间不足风险 | 构建和日志可能挤满系统盘 | 项目 release、运行数据和容器工作目录放入数据盘；只迁移必要数据后停止无目的迁移 | 根盘恢复安全余量，部署继续在数据盘完成 |
| DEP-003 | 对象存储桶已创建但缺少 readiness sentinel | API readiness 失败 | bootstrap 在建桶、启用版本后写入并校验 sentinel | `/api/v1/ready` 的对象存储组件为 ready |
| DEP-004 | Kimi 凭证曾出现在会话中 | 凭证泄露风险 | 只存本机和服务器 0600 私密 env，不写源码、Git、日志；增加有期限体验例外 | Kimi L3 真实生成通过；商业发布仍要求轮换 |
| DEP-005 | DeepSeek v4-pro 无额度，v3.2 有下架窗口 | 新任务产生已知阻塞样本 | DeepSeek 保持 disabled；新检测只给已配置且启用的 Provider 建任务 | active provider scope 契约测试；历史阻塞证据保留不删除 |
| DEP-006 | Provider 健康页每次加载同步执行 L3 真实生成 | 页面长时间 loading，并可能重复计费 | 页面改读数据库中最近一次不可变 L3 probe；新探测由发布/运维门禁显式执行 | 健康快照测试证明页面读取不会调用 live probe |
| DEP-007 | 普通账号看到英文权限和复测错误 | 中文产品体验不完整 | API 核心错误改中文，Web 增加按错误码中文映射和未知错误安全回退 | 前端契约、TypeScript 构建、浏览器复验 |
| DEP-008 | Skill/设置接口无权限时仍显示默认 0、unavailable、blocked | 默认值可能被误解为真实业务状态 | 加载、无权限、空数据三态分开；接口失败时隐藏 Skill 汇总 | 前端状态契约和浏览器复验 |
| DEP-009 | 登录页暴露旧底座文案和英文 | AIRank 品牌不一致 | 登录页统一 AIRank LOGO、中文字段和中文提示，不展示旧底座名称 | 登录品牌契约和 Computer Use 视觉验收 |
| DEP-010 | 部署重启期间一条豆包任务租约过期 | 扫描批次出现失败槽位 | 保留失败 Answer/Evidence，不删除、不改写为成功；后续新批次按真实状态重跑 | 证据中心可下钻失败代码和不可变 hash |
| DEP-011 | 无权限账号仍能看到价格录入表单和“暂无版本” | 操作能力与空数据结论均可能被误判 | 加载、无权限和已加载三态分离；无权限时只显示明确错误，不渲染表单或空数据 | Computer Use 发现后补充前端契约并重新复验 |
| DEP-012 | 任务中心历史失败原因和状态为英文 | 客户无法快速理解真实失败边界 | 保留不可变错误码，前端只将状态与说明映射为中文；数据库原始错误不覆盖 | 任务中心 Computer Use 下钻和前端契约 |

## 当前仍为门禁而非缺陷

- Kimi 旧凭证必须在体验例外到期前轮换；到期或进入商业发布角色时自动失败关闭。
- DeepSeek 在开通可持续型号额度并完成迁移验证前保持 disabled。
- Consumer Web/App 四平台真实 L3、客户发布站点回执、生产 KMS/HSM 和真实客户完整复测窗口尚未完成，因此不能声明“商业可上线”。
- 无平台管理员权限的体验账号只能查看客户侧页面；管理员控制台显示明确的“无权限或不可用”，不会伪造管理数据。
