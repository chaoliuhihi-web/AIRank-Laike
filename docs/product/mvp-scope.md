# AIRank 30 天 MVP 范围

## 必须完成

| 模块 | 目标 | 工程落点 |
| --- | --- | --- |
| 品牌项目 | 录入企业、官网、行业、产品、服务、客户、目标 | `apps/api/modules/projects` |
| 竞品管理 | 支持 3-10 个竞品 | `apps/api/modules/competitors` |
| AI 来客问题地图 | 生成 50 个高购买意图问题 | `apps/api/modules/questions` |
| 多 AI 平台扫描 | 保存平台、问题、回答原文、快照、引用 URL | `apps/worker/jobs/scan` |
| AIRank 来客指数 | 计算提及率、推荐率、引用率、竞品压制、事实一致性 | `packages/score` |
| 竞品压制分析 | 找出竞品出现但客户缺席的问题和来源 | `apps/api/modules/gaps` |
| 引用来源归因 | 区分客户、竞品、第三方来源 | `packages/evidence` |
| 品牌可信事实库 | 从官网、PPT、案例、资质、问答沉淀事实 | `packages/kb-lite` |
| 可信事实卡 | 客户侧展示的事实卡；工程内部用 FactAtom 表示最小事实单元、来源、可信等级、可公开程度 | `packages/domain/src/fact-atom` |
| 内容缺口工厂 | 把差距转成内容生产任务 | `apps/api/modules/gaps` |
| 内容资产生成 | FAQ、选型指南、客户案例页 | `apps/worker/jobs/content` |
| 发布包导出 | 官网正文、Meta、FAQ Schema、Article Schema、社媒版本 | `apps/worker/jobs/publish` |
| 复测报告 | 用同一批问题复测变化 | `apps/worker/jobs/retest` |
| 高管报告 | 面向老板的机会、差距、动作和变化 | `apps/api/modules/reports` |

## 可以半自动

- 中文 AI 平台扫描
- 引用来源识别
- 可信事实卡生成
- 内容审校
- 发布状态追踪

半自动也必须有结构化记录，不能只停留在人工备注。

## 30 天不做

- 无审核全自动发布或授权自动推送
- 复杂权限
- 复杂计费
- 代理商后台
- 白标
- 完整 CMS
- 全平台自动采集

## 第一版验收路径

1. 新建一个企业品牌项目。
2. 录入官网、行业、产品、服务、目标客户和竞品。
3. 生成买家问题地图。
4. 对至少 5 个中文 AI 平台完成扫描或半自动采样。
5. 保存回答快照和引用来源。
6. 生成 AIRank 来客指数。
7. 输出竞品压制问题和内容缺口。
8. 创建可信事实卡。
9. 生成 FAQ、选型指南、案例页。
10. 导出发布包。
11. 记录发布 URL 或发布状态。
12. 对同一问题集复测。
13. 生成高管报告。
