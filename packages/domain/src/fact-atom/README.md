# fact-atom — 可信事实卡内部事实元

FactAtom 是 AIRank 来客的**核心数据对象**，也是客户侧“可信事实卡”的内部最小事实单元。

对外产品、官网、销售材料和控制台文案继续使用“可信事实卡”；代码、schema、数据库和事件中使用 `FactAtom`。

## 设计原则

> 没有可信事实卡 / FactAtom，不允许生成公开内容。
> 没有人工确认，不允许进入发布包。

FactAtom 不是法律意义上的证据，而是一个"可被内容生产复用的事实单位"。

## 核心规则

1. 没有可信事实卡 / FactAtom，不允许生成公开内容。
2. 没有人工确认，不允许进入发布包。
3. C / D 级事实不能直接用于官网或第三方信源稿。
4. 所有内容必须能追溯到事实来源。
5. 涉及客户案例必须确认可公开。
6. 涉及竞品对比必须确认客观和合规。
7. 涉及价格、效果承诺必须人工确认。

## 字段

参见 `docs/decisions/terminology.md` 中"可信事实卡 / FactAtom"字段表。

## 事实类型

```text
企业身份事实
产品服务事实
客户案例事实
行业方案事实
资质荣誉事实
价格服务事实
常见问题事实
竞品差异事实
发布渠道事实
```

## 可信等级

```text
A (OFFICIAL)：官方资料 / 客户授权 / 可公开案例
B (CONFIRMED)：内部资料 / 销售材料 / 已确认事实
C (PENDING)：待确认资料 / 历史材料 / 需复核
D (RESTRICTED)：不可用于生成公开内容
```

## 可公开程度

```text
public       公开可用
redacted     需脱敏
internal     内部参考
forbidden    禁止公开
pending_approval  需客户确认
```

## 与其他模块的关系

- 事实元来自 `fact-store`（企业事实库），经过拆解和标注后成为独立数据对象。
- 内容资产（`asset`）生成时必须引用事实元 ID。
- 审核控制台（`review-console`）负责人工确认事实元的可信等级和可公开程度。
- 证据包（`evidence`）在报告中追溯事实元的原始来源。
