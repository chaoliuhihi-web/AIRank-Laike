# fact-store — 企业事实库

企业事实库（FactStore）是可信事实卡内部事实元的存储和检索层。

## 职责

把企业分散在官网、PPT、案例、白皮书、销售问答、历史文章里的资料，沉淀成可复用、可审核、可生成内容的事实库。

## 事实类型

```text
企业简介
核心服务
典型案例
资质与荣誉
联系方式
产品参数
服务价格
行业方案
客户问答
竞品差异
```

## 每个事实模块显示状态

```text
已确认
待确认
可公开
需脱敏
已用于内容
已发布
已被引用
```

## 用户操作

```text
查看事实
确认事实
标记可公开程度
补充缺失事实
生成可信事实卡 / FactAtom
```

## 与 fact-atom 的关系

- FactStore 是资料汇集层，对应 PRD 的"企业事实库"页面。
- FactAtom 是从 FactStore 中拆解出的最小可复用事实单元，对外呈现为"可信事实卡"。
- 一个 FactStore 条目可以拆解为多个 FactAtom。

## 与 kb-lite 的关系

- `packages/kb-lite` 提供底层存储和检索能力（SQL + 简单向量检索）。
- `fact-store` 是领域模型层，定义业务逻辑和状态流转。
- `kb-lite` 是基础设施层，提供存储引擎。
