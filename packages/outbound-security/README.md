# packages/outbound-security

AIRank 自有的统一出站网络安全边界，供官网抓取、页面诊断、发布器和后续通用 HTTP
连接器复用。

核心约束：

- 默认只允许无凭据的 HTTPS URL；
- DNS 解析结果必须全部为公网地址；
- 拒绝 localhost、私网、链路本地、CGNAT、保留地址、IPv4-mapped IPv6 和过渡地址；
- 连接固定到已经校验的 IP，TLS 仍使用原始主机名完成 SNI 和证书校验；
- 重定向逐跳重新校验，跨域时移除授权、Cookie 和 API Key 类请求头；
- 禁止压缩响应并执行声明长度与实际读取长度双重上限；
- 不读取系统代理，避免凭证流入未受信代理。

该包只提供网络安全和响应字节边界，不负责业务事实判断、页面技术评分或品牌可见度评分。
